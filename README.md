# OportuLab

Laboratorio de oportunidades — Emprendedurismo I.


Recorrido interactivo para identificar y desarrollar oportunidades de emprendimiento.
Desarrollado por [eQuantum Consulting](https://equantum.com.py).

## Estructura

```
index.html                                  # App completa (HTML + CSS + JS embebidos)
assets/oportulab_siguientes_pasos_v3.mp4    # Video "Siguientes pasos"
```

## Despliegue

Sitio estático, sin build. En Vercel: importar el repo con
**Framework Preset: Other**, sin Build Command ni Output Directory.

## Notas

- El progreso de cada usuario se guarda en `localStorage` de su navegador;
  no hay backend ni se recopilan respuestas.
